# 🤝 Руководство по участию

Спасибо за интерес к проекту! Вот как можно помочь.

## 🐛 Сообщить об ошибке

1. Проверьте, не создан ли уже [Issue](https://github.com/yyangdev/majestick-famq-discord-bot/issues) с похожей проблемой.
2. Если нет — создайте новый с подробным описанием:
   - Что ожидалось
   - Что произошло
   - Шаги для воспроизведения
   - Логи из консоли / `logs/bot.log`

## 💡 Предложить улучшение

Откройте Issue с тегом `enhancement` и опишите:
- Зачем нужна фича
- Как она должна работать
- Пример использования

## 📝 Pull Request

1. Форкните репозиторий
2. Создайте ветку: `git checkout -b feature/название`
3. Внесите изменения
4. Убедитесь, что **все тесты проходят** (переменная `TOKEN` должна быть задана — подойдёт любое значение):
   ```bash
   cd src/app
   TOKEN=dummy python -m unittest discover -s tests -v
   ```
5. Проверьте линтер и форматтер:
   ```bash
   ruff check .
   ruff format --check .
   ```
6. Закоммитьте и запушьте
7. Откройте Pull Request

## 📋 Требования к коду

- Минималистичный стиль
- Все тексты и настройки — в `config.py`
- Новый функционал покрывается тестами
- Не ломайте существующие тесты
- Код проходит `ruff check .` и `ruff format --check .`
