# Команды и кнопки

## Команды

| Команда | Кто может | Что делает |
|---------|-----------|-----------|
| `!regent` | Все | Показывает панель с кнопками «RP ЗАЯВКА» и «CAPT ЗАЯВКА» |
| `!stats` | Администраторы | Сводка по заявкам: всего, принято, отклонено, открыто |
| `!history [N]` | Администраторы | Последние N заявок (по умолчанию 10) |
| `!afk` | Все | Меню управления своим AFK-статусом |
| `!afk_list` | Все | Список всех, кто сейчас в AFK |
| `!afk_check @user` | Все | Статус конкретного пользователя |
| `!afk_stats @user` | Все | Статистика AFK конкретного пользователя |
| `!afk_remove @user` | Модераторы | Принудительно снять AFK с пользователя |

Команды работают только на сервере, в личке боту писать бессмысленно.

## Как проходит заявка

1. Пользователь пишет `!regent` и жмёт кнопку типа заявки.
2. Открывается форма. После отправки бот:
   - выдаёт роль «Подал заявку»,
   - шлёт в личку подтверждение,
   - создаёт приватный канал вида `rp-ник` или `capt-ник`,
   - постит туда карточку заявки и кнопки,
   - пингует рекрутёров.
3. Заявка пишется в базу со статусом `open`.

## Кнопки в тикете

| Кнопка | Что происходит |
|--------|----------------|
| «Принять» | Форма с причиной - запись в лог-канал - статус `accepted` - канал удаляется |
| «Отказать» | Форма с причиной - запись в лог-канал - статус `denied` - канал удаляется |
| «Вызвать на обзвон» | Выбор голосового канала - заявитель пингуется в тикете |
| «Закрыть тикет» | Канал удаляется без вопросов и без записи в лог |

Кнопки сейчас **не проверяют права** - нажать их может и сам заявитель. Это известная дыра, issue #17, исправление в первую очередь. Пока фикса нет, просто имейте в виду.

Ещё кнопки «умирают» после перезапуска бота (issue #16). Чтобы они снова заработали, заявку нужно переоткрыть заново запостив панель.

## Кнопки меню `!afk`

| Кнопка | Что происходит |
|--------|----------------|
| «🔴 Взять AFK» | Форма: причина (необязательно) + на сколько (обязательно) |
| «🟢 Отменить AFK» | Окно подтверждения с длительностью отсутствия |
| «📋 Список AFK» | Тот же список, что `!afk_list`, виден только вам |

Подробности устройства AFK - в [afk.md](afk.md).

## Права администраторов

`!stats` и `!history` закрыты правом «Администратор» Discord (не ролью из конфига). Кнопки тикетов («Принять», «Отказать», «Закрыть тикет», «Вызвать на обзвон») и `!afk_remove` доступны модераторам: право Discord (админ / управление сервером / управление сообщениями) или стафф-роль по ID из `.env`. Все команды работают только на сервере (в ЛС бот ответит об этом). Если прав не хватает или аргумент неверный - бот отвечает понятным текстом, а не молчит; неожиданные ошибки падают в ветку `🚨-ошибки` лог-центра.
