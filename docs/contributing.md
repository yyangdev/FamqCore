# Как помочь проекту

Проект в бете и активно растёт - помощь очень нужна, и не только кодом.

## Кого ищем

- **Python-разработчики.** В [трекере](https://github.com/yyangdev/majestick-famq-discord-bot/issues) почти сотня задач на любой вкус: от «поправить строку» до «спроектировать миграции».
- **Тестировщики.** Поднять бота на своём тестовом сервере, погонять сценарии из [commands.md](commands.md) и назаводить багов.
- **Писатели и идейные.** Тексты для пользователей, идеи сценариев, вот всё это можно улучшать без единой строчки кода.

Не отговорим никого: даже если вы только учитесь, найдём задачу по зубам и поможем довести до PR.

## С чего начать

1. Посмотрите [Issues](https://github.com/yyangdev/majestick-famq-discord-bot/issues) и отпишитесь в задаче, что берёте её.
2. Хорошие первые задачи (относительно простые и понятные):
   - #79 - сократить лейбл в RP-форме и добавить проверку лимитов конфига
   - #85 - защитить кнопки меню AFK от вызова в ЛС
   - #58 - показать недельную статистику в `!stats`
   - #69 - фоновая задача авто-снятия AFK по времени
3. Сверьтесь с критичным списком в [ROADMAP #99](https://github.com/yyangdev/majestick-famq-discord-bot/issues/99) - если чувствуете силы, берите оттуда.

## Процесс

Коротко, подробности в [CONTRIBUTING.md](../CONTRIBUTING.md):

1. Форк и ветка `feature/что-делаете` или `fix/номер-issue`.
2. Код. Держим минимализм, тексты - только через `config.py`.
3. Тесты на новое поведение.
4. Проверки перед PR:
   ```bash
   cd src/app
   TOKEN=dummy python -m unittest discover -s tests -v
   ruff check .
   ruff format --check .
   ```
5. PR с описанием: что сделано, зачем, какой issue закрывает.

## Стиль кода

- PEP8, ruff форматтер решает спорные места, не спорим с ним.
- Маленькие функции, вложенность до двух уровней.
- Комментарии - только там, где непонятно «почему», а не «что».
- Без прослоек «на будущее» - делаем то, что нужно сейчас, просто аккуратно.

## Не кодом тоже можно

- Нашли баг - issue с шагами воспроизведения.
- Есть идея - issue с заходом «зачем это нужно» и «как видите работу».
- Хотите потестить пре-релиз на своём сервере - скажите, дадим инструкцию.
